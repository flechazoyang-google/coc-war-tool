# COC War Tool v4.11.0

发布日期：2026-09-09
Version Code：40

## ⚠️ 本版本需先卸载旧版再安装

从 v4.11.0 起安装包改用**专用发布签名**（此前为开发调试签名）。Android 不允许签名不同的安装包覆盖安装，
因此已装 v4.10.0 及更早版本的用户，请**先卸载旧版，再安装本版本**。

> 建议先用「设置 → 数据管理 → 导出备份（ZIP）」保存数据，安装新版后再导入还原。
> 后续版本恢复正常，可直接在 App 内一键更新。

## 变更内容

- 🔄 **更新渠道迁移**：版本检查与安装包下载迁移至 GitHub Releases，更新提示更及时（不再受 CDN 缓存影响）
- 🧹 设置 → 更新页移除「加入测试计划」开关：只提供正式版，不再发布 alpha/beta/rc 测试通道
- 📦 安装包改为 R8 混淆 + 资源压缩的 release 包，体积更小
- 🛠 发布流程与个人工具箱项目统一：一条命令完成版本号、测试、构建、归档与发布

## 校验

- 单测：264 用例 / 0 失败（26 个测试文件）
- 构建：`:COCtools:clean :COCtools:assembleRelease` BUILD SUCCESSFUL
- 签名：apksigner 校验通过（v2 方案，专用发布证书）
- 版本：aapt2 校验 versionCode=40 / versionName=4.11.0
