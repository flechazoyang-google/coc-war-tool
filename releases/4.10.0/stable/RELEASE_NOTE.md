## 更新内容

正式版：花名册重构（离队即删除）+ 成员更新流程 + 解析容错加固

- **离队即删除（软替换 → 硬替换）**：「更新花名册」整体替换语义由「标记离队」改为「直接删除」——不在新名单的成员从花名册真正移除（战报数据不受影响）；移除「已离队成员」页与软离队概念，启动兜底清理旧版遗留的离队行；疑似离队清理改为「移出」（Snackbar 可撤销，撤销连职位一起还原）
- **成员更新流程**：花名册页菜单新增「成员更新」入口 → 复制动态提示词（注入当前在册名单 + 易混名提醒）→ 悬浮球截取成员页 → 外部 AI 提取 → 粘贴回 App；预览页逐人勾选退出/新增，确认后一次性硬替换
- **50 人上限**：花名册上限 50 人，更新后超员禁止确认并提示核对识别结果
- **解析容错加固**：表头「名字,职位」（及昵称/姓名变体）自动跳过；职位字段含多余逗号的整行判为格式异常、不入库
- **职位归一化**：游戏内成员页「长者」与「长老」等价
- **测试**：单测 258 用例 / 26 文件全绿
