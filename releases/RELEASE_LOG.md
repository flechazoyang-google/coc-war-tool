# COC War Tool 发行版日志

## v4.8.0 (2026-08-24)

正式版：OCR 设置重构 + 战报页重构 + 截图列表分组 + 导入页优化 + 剪切板导入日期选择

- **OCR 设置重构**：服务商选择改为下拉菜单（百炼/agnes-ai/自定义）；新增「从 API 获取模型列表」按钮（调用 `/models` 端点，支持搜索过滤）；新增「测试连接」按钮（发送最小请求验证 API Key 与模型可用性）；模型选择支持手动输入或从 API 列表选择
- **战报页重构**：右上角操作改为「更多」下拉菜单（导入战报/读取剪切板/截图列表/战报筛选）；筛选条件移入对话框（FilterChip 选择类型/年份/月份）；副标题显示当前筛选状态；下拉菜单紧凑化（小字体 + 小图标）
- **战报日期显示**：战报列表每场战报下方显示「X月X日」（如「部落战 · 6月15日」），取导入时选择的日期
- **剪切板导入统一**：剪切板导入弹窗新增日期选择器（与手动粘贴导入流程一致），选择日期后自动调整事件名称与 createdAt 时间戳
- **剪切板支持 CSV**：读取剪切板时自动检测 CSV 格式（表头关键词 + 数据列模式），CSV 数据直接走 `CsvImporter.parse()` 解析
- **截图列表分组**：截图库改为按日期分组的列表视图（每组显示日期 + 图片数量，点击展开 3 列缩略图网格）；修复 `dateAdded` 毫秒/秒转换问题
- **导入页优化**：右上角新增帮助图标，点击显示完整提示词（小字体 + 背景框），复制按钮改为图标按钮（ContentCopy）紧邻关闭按钮；新增战报日期选择器（导入时自动设置事件日期）
- **Bug 修复**：修复悬浮球权限对话框获取权限后不自动消失的问题（添加 LifecycleObserver 监听 resume 事件自动关闭对话框）
- **测试**：单测 212 用例全绿

- **APK**: 见 Gitee Release 附件（`COCtools-v4.8.0.apk`，不入库）
- **Version Code**: 32

## v4.7.2-preview (2026-08-21)

预览版：识图客户端协议修复 + 默认后端切为 agnes + 空返回自动重试

- **识图协议修复**：`OcrClient` 请求体图片块补齐标准 OpenAI 多模态 `type: image_url` 字段 —— 此前仅 DashScope 容忍缺省，严格校验的兼容服务（如 agnes-ai）会直接 HTTP 500，现所有 OpenAI 兼容服务通用

- **测试**：单测 194 用例全绿（OcrClient 9→10：新增 type 协议断言 + 空返回重试用例）
